# Capturas de verificación visual

Capturas de los componentes reales de Angular en Chrome, con respuestas controladas de prueba, sin guardar registros en Laravel ni PostgreSQL.

- `mis-solicitudes.png`: pestañas, indicadores, lupa y filtro Estado.
- `nueva-solicitud.png`: formulario compacto de dos columnas sin sede manual.
- `solicitud-con-scroll.png`: Header y Sidebar conservan su posición.
- `nueva-movil.png`: formulario adaptable en viewport móvil de 390 × 844.

El arnés temporal empleado para generar estas imágenes fue retirado; no se añadieron datos de prueba a la aplicación.
